😮‍💨 매일 반복되던 문제 4가지

  • 월 200건+ 신규 리뷰 — 답변 작성에 매일 1~2시간 (건당 15~20분)
  • 2개 스토어 별도 관리 — Play Console·App Store Connect를 오가다 답변 누락 빈번

🎯 그래서 목표 4가지

  • 즉시 인지신규 리뷰 발생 시 Google Chat 실시간 알림
  • AI 답변 초안Claude가 별점·내용에 맞춰 자동 생성 — 사람은 복붙만
  • 누락 방지24시간 답변 없으면 리마인드 자동 재발송
  • 이력 관리모든 리뷰·답변을 Google Sheets에 자동 백업
문제를 인지 지연 · 누락 · 톤 비일관 · 이력 부재로 쪼개니 — 만들 기능 4개가 그대로 나왔습니다.

느낀 점 ① — 도구 선택이 프로젝트의 절반이었다

n8n(시각적 워크플로우)과 Python 스크립트, 두 트랙을 다 만들어보고 알게 된 것.

🔀 n8n 트랙 — 기대와 현실

  • 기대: 시각적 노드라 팀원 누구나 수정 가능, 24노드 파이프라인 완성
  • 현실: 트러블 7건 중 5건이 n8n에서 발생 — OAuth IP 차단, 노드 보안 정책, 배치 분기 인덱스 반전…
  • "쉬워 보이는 도구"의 제약을 우회하는 데 쓴 시간이, Python으로 그냥 짜는 시간보다 길었음

🐍 Python 트랙 — 주력이 된 이유

  • Claude Code와 함께라면 코드가 곧 문서"이 스크립트 뭐 하는 거야?" → AI가 바로 설명·수정
  • dry-run·백필·리마인드 같은 운영 장치를 자유롭게도구의 제약이 아니라 업무의 요구가 설계를 결정
  • 결국 일별 모니터링은 Python 단일 트랙으로 수렴
교훈 — 도구는 "내가 편한 것"이 아니라 "막혔을 때 뚫을 수 있는 것"으로. 비개발자여도 AI와 함께면 코드가 더 뚫기 쉬웠습니다.

Part 1 · Lessons

느낀 점 ② — 자동화의 8할은 만들기가 아니라 '운영 설계'

1
문제를 쪼개니 기능이 저절로 나왔다
"리뷰 답변이 오래 걸린다"가 아니라 인지 지연 · 답변 누락 · 톤 비일관 · 이력 부재로 쪼개자 — 알림·리마인드·초안·시트라는 4개 기능이 그대로 도출.
문제 정의 30분이 기능 기획 회의 몇 번을 대체
2
가장 지루한 백필이 가장 중요했다
과거 답변 499건 백필과 기존 리뷰 275건 마킹 — 이게 없었으면 첫날부터 중복 알림 폭탄. Airbnb가 AI CS 전에 데이터 정리에 2년을 쓴 이유를 체감.
"데이터 정리부터"는 진리였다
3
AI는 초안까지, 발송은 사람 — 이게 신뢰를 만들었다
초안을 자동 발송하지 않고 복붙 승인 구조로 남겨두니, 팀이 결과물을 의심하지 않고 도구를 받아들임. 자동 발송이었다면 오답 리스크를 회사가 그대로 떠안았을 것.
Human-in-the-loop = 채택률의 조건
4
완성 선언보다 --dry-run이 먼저
실 웹훅에 테스트 발송을 쏘는 사고를 막아준 건 처음부터 넣어둔 dry-run 플래그. 검증 없이 "완료"라고 말할 뻔한 순간이 여러 번.
돌려보기 전까지는 완료가 아니다

Part 2 · Reusable

공유하고 싶은 점 — 다음 과제에 그대로 가져다 쓸 수 있는 것들

이 프로젝트에서 나온 재사용 가능한 패턴 5가지 — 여러분 과제에 복사해 가세요.

🔐
config.example 패턴시크릿 분리
웹훅 URL·API 키는 config.yaml(git 제외)에, 커밋은 example 파일만. 3강 거버넌스 "API 키 프롬프트 금지"의 저장소 버전.
🧪
--dry-run 먼저발송 없는 리허설
발송·기록이 있는 자동화라면 미발송 테스트 모드를 1일차에 만들기. 검증 비용이 10분의 1로.
🃏
복붙 가능한 카드 UX도입 장벽 제거
Chat 카드에 초안 전문 + "답변하기" 바로가기 버튼 — 새 도구를 배울 필요가 없게 하니 팀이 바로 씀.
🧩
스킬로 배포.claude/skills
실행법을 스킬 문서로 저장소에 동봉 — 내가 없어도 팀원이 Claude Code로 재실행 가능.
🗺️
트러블 기록 = 자산다음 장 참고
이슈 7건을 원인·해결까지 기록 — 같은 스택을 쓸 다음 사람의 며칠을 아껴줍니다.
📈
수치로 말하기Before → After
"편해졌어요"가 아니라 1~2시간 → 10~20분. 설득은 형용사가 아니라 숫자가 합니다.
