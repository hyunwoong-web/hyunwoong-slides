😮‍💨 매일 반복되던 문제 4가지

  • 월 200건+ 신규 리뷰 — 답변 쓰는 데만 시간이 꽤 들어감

  • 새 리뷰를 뒤늦게 발견 — 불만 고객을 제때 챙기기 어려움

🎯 그래서 목표 4가지

  • 즉시 인지신규 리뷰 발생 시 Google Chat 실시간 알림
  • AI 답변 초안Claude가 별점·내용에 맞춰 자동 생성 — 사람은 복붙만
  • 누락 방지24시간 답변 없으면 리마인드 자동 재발송

느낀 점 ① — 도구 선택이 프로젝트의 절반이었다

n8n(블록을 이어 붙이는 자동화 도구)과 Python(직접 짜는 코드) — 둘 다 만들어보고 나서야 알게 된 것들입니다.

🔀 n8n 트랙 — 기대와 현실

  • 기대 — 블록을 이어 붙이는 방식이니 팀원 누구나 고칠 수 있겠지, 하며 블록 24개짜리 흐름까지 완성
  • 현실 — 문제 7건 중 5건이 n8n에서 발생: 구글 인증 거부, 막혀 있는 기능, 반복 처리 연결이 반대로 꽂힘…
  • '쉬워 보이는 도구'의 제약을 우회하는 데 쓴 시간이, Python으로 그냥 짜는 시간보다 길었습니다

🐍 Python 트랙 — 주력이 된 이유

  • Claude Code와 함께라면 코드가 곧 문서"이 스크립트 뭐 하는 거야?" → AI가 바로 설명·수정
  • 발송 없는 리허설·과거 데이터 채우기·리마인드 같은 운영 장치를 자유롭게도구의 제약이 아니라 업무의 요구가 설계를 결정
  • 결국 일별 모니터링은 Python 단일 트랙으로 정리했습니다
교훈 — 도구는 '내게 편해 보이는 것'보다 '막혔을 때 뚫고 나갈 수 있는 것'을 골라야 합니다. 비개발자인 저도, AI와 함께라면 오히려 코드 쪽이 뚫기 쉬웠습니다.

느낀 점 ② — 자동화의 8할은 만들기가 아니라 '운영 설계'

1
문제를 쪼개니 기능이 저절로 나왔다
"리뷰 답변이 오래 걸린다"가 아니라 인지 지연 · 답변 누락 · 톤 제각각 · 이력 부재로 쪼개고 나니 — 알림·리마인드·초안·시트라는 기능 4개가 그대로 나왔습니다.
문제 정의에 쓴 30분이 기획 회의 몇 번을 아껴줬습니다
2
가장 지루한 '과거 데이터 채우기'가 가장 중요했다
과거 답변 499건을 시트로 되살리고, 기존 리뷰 275건을 미리 정리해 둔 것 — 이게 없었다면 첫날부터 중복 알림이 쏟아졌을 겁니다. Airbnb가 AI 상담을 열기 전에 데이터 정리부터 했다는 게 이해됐습니다.
'데이터 정리부터'는 진리였습니다
3
AI는 초안까지, 발송은 사람 — 이게 신뢰를 만들었다
초안을 자동 발송하지 않고 복붙 승인 구조로 남겨두니, 팀이 결과물을 의심하지 않고 도구를 받아들였습니다. 자동 발송이었다면 오답 리스크를 회사가 그대로 떠안았을 겁니다.
마지막 판단을 사람에게 남긴 것이, 팀이 받아들인 조건이었습니다
4
완성 선언보다 '발송 없는 리허설'이 먼저
테스트하다 진짜 채팅방에 발송하는 사고를 막아준 건, 처음부터 넣어둔 미발송 시험 모드였습니다. 검증 없이 "완료"라고 말할 뻔한 순간이 여러 번 있었습니다.
돌려보기 전까지는 완료가 아닙니다

n8n·구글 연동·Chat 알림에서 만난 문제들 — 겪기 전에 알면 며칠이 절약됩니다.

#문제원인해결
1구글 시트 연결이 거부됨정식 인터넷 주소가 없는 서버는 구글이 인증을 막음서버에 정식 주소를 발급해서 연결
2필요한 기능이 n8n에서 안 보임보안상 꺼져 있는 기능이었음그 단계만 Python으로 분리
3애플 리뷰가 0건으로 읽힘응답 형식을 자동으로 알아채지 못함글자 그대로 받아서 직접 해석하도록 변경
4시트 기록이 한도 초과로 막힘150건을 한 건씩 따로따로 호출한 번에 몰아서 기록하도록 변경
5리뷰가 처리되지 않고 건너뜀반복 처리의 출구 연결이 반대로 꽂혀 있었음연결을 바로잡음
6알림 카드가 깨져서 안 옴AI 답변 속 이모지·줄바꿈이 전송 형식을 깨뜨림특수문자를 안전하게 감싸서 전달 — AI가 쓴 글을 시스템에 넣을 땐 필수
7갱신할 줄을 시트에서 못 찾음어느 줄인지 알려주는 값이 빠져 있었음리뷰 고유 번호를 명시해서 찾도록 수정
패턴 — 7건 중 5건이 도구(n8n)의 제약, 2건이 AI가 쓴 글을 시스템에 넣는 이음새에서 났습니다. 자동화가 멈추는 곳은 계산이 아니라 연결 부위입니다.
