Problem

왜 — 등록 방이 경매에 넘어가도, 알 방법이 없었습니다

방이 경매로 넘어가면 임차인의 보증금과 계약이 위험해집니다.

⚠️ 손 놓고 있을 수밖에 없던 이유

  • 전국 진행 경매 2만 건+ — 사람이 비교 불가
  • 매일 수천 건씩 변동
  • 법원 사이트는 한 건씩 검색만 가능
  • 알게 될 땐 이미 늦은 뒤

🎯 그래서 목표 4가지

  • 매일 전국 수집
  • 등록 방과 자동 대조 — 동·호수까지
  • 변동이 있는 날만 알림
  • 확인 · 조치 · 기록을 한 화면에서
한 줄로 — "경매 넘어간 방에서 계약이 진행되는 일"을 막는 조기 경보.

Detail 2 · Matching

구현 상세 ② — "같은 집인가?"를 동·층·호수까지 따집니다

📐 판정 규칙 — 동(棟)·층 4가지

1경매에만 동이 있으면 → 다른 집
2방에만 동이 있으면 → 같은 집 인정
3동 이름이 다르면 → 다른 집
4층이 다르면 → 다른 집 (503호=5층 추정까지)
전부 운영팀의 "이거 다른 집인데요?" 제보에서 나온 규칙입니다.

🗂️ 처리현황 탭 열기 ↗

  • 사건번호 · 호스트 · 진행 계약 자동으로 채움
  • 일치가 풀리면 이유도 자동 구분
  • 운영팀은 처리상태 칸만 기록

🔌 사내 주소검색 API — 주고받는 데이터

보내는 것경매 물건의 지번주소 한 줄 — 호출 한도 안에서 천천히
받는 것등록 방 목록 — 고유 번호 · 주소 · 동·호수 · 진행 계약 (개인정보 없음)
넓혀 찾기부번·건물명 붙은 주소 후보까지 함께
개발팀 현희님이 요청 사항에 맞춰 제작해 주신 API입니다 — 덕분에 전국 전수 대조가 가능해졌습니다. 감사합니다 🙏

💬 알림 — 조용해야 오래 갑니다

  • 변화가 있는 날만 발송
  • 카드에는 건수 요약만 — 상세는 시트에
  • 단계만 바뀐 건 다시 세지 않음 — 이중 알림 방지
  • 점검용 실행은 알림 없이 도는 게 기본값

⚖️ 수집 원칙 — 판례를 보고 선을 그었습니다

1공개 데이터만 — 로그인·우회 없음
2천천히 — 막히면 쉬었다 재시도
3채무자·소유자 이름은 저장 안 함
4사내 용도 한정 · 외부 공유 금지
5대상은 국가기관의 공개 공고문
자동화보다 선 긋기가 먼저였습니다.

Part 1 · Lessons

느낀 점 ① — 이번엔 n8n이 정답이었습니다

앱 리뷰 과제와 정반대 결론이 났습니다.

🔁 왜 반대 결론인가

  • 앱 리뷰 — 하루 몇 건, 사람이 승인 → 내 PC의 Python
  • 이 과제 — 매일 2만 건, 혼자 돌아야 함 → 꺼지지 않는 서버
도구에 정답은 없고, 일의 성격이 도구를 고릅니다.

🧗 서버의 제약에 맞춘 설계

  • 5분 제한 → 지역 묶음으로 분할
  • 용량 한계 → 바뀐 것만 전달
  • 호출 한도 → 천천히, 막히면 쉬기
제약을 우회하지 않고 제약에 맞는 구조를 짰더니 오히려 안정적입니다.

느낀 점 ② — 데이터 모으기는 시작일 뿐이었습니다

1
가치는 수집이 아니라 대조와 알림에서
2만 줄 시트만 있었다면 아무도 안 열었을 겁니다.
결과물은 '사람이 움직일 수 있는 신호'
2
판정 규칙은 현장에서 나왔다
동·층 규칙 전부 운영팀 제보에서 — 지금도 다듬는 중입니다.
설계 문서 = 운영팀의 제보 목록
3
알림은 필요할 때만
다 알리면 채널이 무시당합니다 — 일치 건의 변화만, 요약으로.
알림의 가치는 보내지 않은 날들이 만든다
4
안전은 기본값으로
점검 실행이 진짜 알림을 쏜 뒤 — 수동 실행은 알림 없이가 기본이 됐습니다.
안전은 '조심하기'가 아니라 '기본값'

공유 — 바깥 데이터를 지켜보는 일의 공식 6가지

⚖️
선 긋기부터수집 원칙 문서화
우회 없음 · 천천히 · 개인정보 미저장 · 사내 한정.
🧩
쪼개고, 바뀐 것만제한 대응
큰 작업은 묶음으로, 단계 사이엔 바뀐 것만.
🔕
변한 것만 알리기요약 + 기록 탭
알림엔 건수만, 상세는 시트에.
🧪
점검은 조용하게기본값 안전
수동 실행은 알림 없이 — 발송은 따로 켜야만.
🔁
다시 돌려도 안전복구 스크립트
몇 번 돌려도 같은 결과 — 복구가 5분이 됩니다.
📝
시트 설명도 코드로범례 자동화
다시 만들어도 안내가 어긋나지 않게.

Part 2 · Trouble Map

막혔던 곳 7군데 — 같은 길을 가실 분들을 위한 지도

#문제원인해결
1수집이 도중에 끊김단계당 5분 제한지역 묶음으로 분할
2단계 사이에서 서버 멈춤2만 건 통째로 전달바뀐 것만 전달
3주소 API가 접속 차단이름 없는 프로그램 차단이름표 달고 천천히 호출
4'낙찰' 오표시상태 코드를 짐작으로 사용공식 코드표 확인 — 짐작 금지
5Chat 카드 경고 문구봇이 버튼을 처리 못 함버튼 → 글자 링크
6물건 링크가 없음법원 사이트에 바로가기 없음내부 조회 페이지 직접 제작
7이중 알림단계 변경을 새 건으로 인식판단 기준에서 단계 제외
문제는 계산이 아니라 시스템이 만나는 지점에서 났습니다.
