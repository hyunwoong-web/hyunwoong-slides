온보딩 발표 자료의 출처와 집계 기준입니다. 광고비 수치 기준일은 2026년 9월 29일이며, 최신 운영 현황과 다를 수 있습니다.

사용 방법

사이트에서 발표 자료를 열거나, 내려받은 index.html을 브라우저에서 엽니다. 별도 설치는 필요하지 않습니다. ← / → 또는 화면의 이전·다음 버튼으로 이동합니다. S를 누르면 별도 발표자 창이 열리고 메모·현재/다음 슬라이드·타이머를 볼 수 있습니다. 원래 창이 청중 화면입니다. 화면 공유는 청중 창만 선택하세요.

광고비 집계 기준

  • 원본: 광고비 집계 시트의 DB 탭 적재에 사용하는 Airbridge 리포트. 시트 화면을 직접 읽은 값이 아니라 동일 적재 원본을 읽기 전용으로 조회했습니다.
  • 집계 필드: Cost (Channel). 비용 합산만 수행하며 전환·구매액은 합산하지 않았습니다.
  • 기간: 2026.01.01–09.29. 최근 완료 월: 2026.08.01–08.31.
  • 사용자 확인 제외 기준: 캠페인명이 인지도 / 신뢰도 / 이해도로 시작하는 행을 제외. 별도 키워드 추론으로 추가 제외하지 않았습니다.
  • 원본 175,619행, 제외 후 166,939행. 일자·채널·캠페인·소재 복합키 중복0건, 기간 내 날짜 누락0일.
  • 누적 채널 비용 전체 3,234,487,034.69원 − 브랜드 분류 비용 94,479,436.67원 = 3,140,007,598.02원.
  • 소수점 둘째 자리까지 원본 비용을 합산한 뒤, 본문은 억 원 단위로 반올림. 브랜드 콘텐츠 제작비·PPL 협찬비를 별도로 합산하지 않았습니다.
  • VAT·수수료·정산 조정의 포함 여부는 원본 채널 비용 설정에 따릅니다. 재무 장부의 확정 비용으로 간주하지 않습니다.
  • 8월은 달력상 완료 월입니다. 별도 재무 정산 확정 여부를 확인하지 않았으므로 본문은 ‘최근 확정 월’ 대신 ‘최근 완료 월’로 표시했습니다.
  • 9월은29일까지의 누적입니다. 다른 월 전체와 단순 비교해 증감을 단정하지 않습니다.

연간 실적의 해석

  • 2024년 퍼포먼스 성과 보고: 최종 업데이트2025.02.27. 퍼포먼스 집행비25.4억원, 마케팅 총비용26.8억원은 서로 다른 범위입니다.
  • 2025년 퍼포먼스 성과 보고: 최종 업데이트2026.01.07. 퍼포먼스 집행비38.5억원, 마케팅 총비용46.8억원은 서로 다른 범위입니다.
  • 연간 사업 실적을 퍼포먼스 광고 단독 기여나 현웅님 개인 실적으로 표현하지 않았습니다.
  • 2024년 원문 ‘결제완료’와2025년 원문 ‘거래건수’를 병기했습니다. 연장·취소·환불 처리 등의 동일 정의가 확정되지 않아 직접 성장률은 새로 계산하지 않았습니다.
  • 2024년 거래액 ROAS3130%와2025년 수수료 매출 ROAS377%는 직접 비교하지 않았습니다. 174.8÷46.8×100은 약373.5%로 보고서377%와 차이가 있어 본문에서 해당 ROAS 수치를 사용하지 않았습니다.
  • 2024년 매체 수는2월5개,12월11개,연간 보고서 부록13개로 기간이 다릅니다. 본문은 당월 비교입니다.

자동화 사례 근거

  • 앱 리뷰: 기존 app-review-automation-retro 발표 자료. 수집·기록·초안·알림 이후 사람이 검토하고 직접 등록하는 흐름.
  • 외부 지표: external-metrics-monitor 문서·소스. 오래된 GitHub Actions 운영 문구 대신 사용자가 확인한 임시 로컬 운영 상태 반영.
  • 테스트 시트 생성: 사용자 확인한 용도와 스킬명 growth-test-toolkit-final-20260921. 현재 제공 경로에서 원본을 찾지 못했으므로 실제 UI·입력 필드·자동 분석 기능을 재현하지 않았습니다.
